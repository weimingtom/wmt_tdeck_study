# wmt_tdeck_study
[WIP very much] My LilyGo T-Deck (tdeck) and T-Deck Plus study, its MCU is ESP32-S3

## NOTE: Currently all projects are unstable and are with many bugs

## ESP-IDF version: 5.3

## How to build and burn firmware and view debug log
* idf.py build
* idf.py flash
* idf.py monitor
